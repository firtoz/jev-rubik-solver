# Model-selected local view screening

Reused 20 scene-development cases, paired variants. Geometry-only: **11/20** complete target/action decisions. Explicit side/up roles and measured side-center matches: **12/20**. No intention question was asked in this architecture; the offline score requires an eligible target and an acceptable action. Generic move/routine effects remain supplied expertise.

Code renames current directions and centers into JEV's chosen frame. The relations arm additionally computes literal color equality, which is permitted observation assistance. Neither supplies a preferred move or computes candidate outcomes during policy execution. A wrong frame or action is followed unchanged. Tests cover viewpoint color invariants and wrong-choice propagation.

The scoped multi-step scene policy previously achieved 14/20 on these same scenes. Local-view selection did not improve that screen and introduced extraction failures: it sometimes left trapped edges unchanged or selected U turns that cannot move them. Pair-specific model target choices sometimes differed, so this comparison includes full-chain variation, not a controlled effect on one fixed target.

120 calls, no retries/provider errors. Cost $0.003398304; project commitment $5.639465706. No held-out gate or integrations run. Exact records: [screen-results.json](screen-results.json).
