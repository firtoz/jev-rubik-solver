## Main bottleneck

JEV can correctly compare colors or name an intended action in isolation, then fail to apply that result in a routine decision. Typical errors are trying to align an already aligned upper edge, inserting before alignment, picking the wrong insertion side, or turning U to extract a middle edge. Typed validity and preservation of the bottom layer are insufficient: the fixed action vocabulary can guarantee those while the selected move still fails to make useful progress.

The tested pipelines supply substantial algorithm knowledge and still miss their action goals. The strongest reused-development score should not be presented as reliability. Other hypotheses remain possible, including prompt sensitivity, spatial representation mismatch and the model's difficulty applying multiple relations together.

## Options requiring a deliberate choice

1. **Document this as the boundary found.** Publish the reliable heavily taught solver separately from the weaker general-effect policies. The article can explain which judgments composed successfully and which did not.
2. **Allow narrow applicability teaching.** Keep JEV choosing targets, frames and routines, but teach the specific alignment/insertion distinctions that failed. This changes the current “without explicit case-to-answer rules” requirement and must not be counted as achieving it unchanged.
3. **Continue a new, predeclared research hypothesis.** For example, a controlled contrastive-teaching study with matched wrong/right routine examples, frozen unseen scene tests and a new stop rule. This adds expert teaching and is unproven; it should not become another unrestricted wording search.

No confidence threshold, automatic correction or best-of-many vote was added to hide failures. No new paid runs should be launched merely because budget remains.
